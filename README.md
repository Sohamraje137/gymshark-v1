# SachinA

Progressive Web App built with Next.js 16, Auth.js (Google login, JWT sessions), and MongoDB.
It includes admin/user roles, Google Calendar, announcements, messaging, and embedded videos.

**Start with [SETUP.md](./SETUP.md).** It lists the keys you need, how to get them, how to run the app, and how to deploy it.

```bash
cp .env.example .env.local   # fill in values (see SETUP.md)
npm install
npm run dev
```
